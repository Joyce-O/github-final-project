# github-final-project

A simple interest calculator built for a micro-finance startup whose mission is to empower and create opportunities for low-income individuals. This repository marks the team's first step in migrating their codebase from Subversion (SVN) to Git and GitHub.

## About

The core engineering team has relied on SVN for version control. As part of the move to Git, this repository hosts a sample script — a simple interest calculator — along with the community documentation needed to run an open-source project the right way: a license, a code of conduct, and contribution guidelines.

## What it does

Given a principal amount, a time period, and an annual interest rate, the script calculates simple interest.

**Input:**
- `p` — principal amount
- `t` — time period in years
- `r` — annual rate of interest

**Output:**
simple interest = p * t * r / 100



## Usage

```bash
./simple-interest.sh
You'll be prompted to enter the principal, time period, and rate of interest, and the script will output the calculated simple interest.
